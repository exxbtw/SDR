# Отчёт: GNU Radio. Построение FM-радиоприёмника

## Цель работы

Собрать в GNU Radio Companion FM-радиоприёмник на базе SDR-устройства Adalm-Pluto, найти частоту реальной радиостанции и получить на выходе слышимый аудиосигнал.

## Краткая теория

GNU Radio — инструмент с открытым исходным кодом для программно-определяемого радио (SDR). Приёмник собирается из готовых блоков в GNU Radio Companion; при сохранении проекта (в нашем случае QT GUI, язык Python) генерируется скрипт, связывающий блоки между собой. Блоки написаны на C++, их связка — на Python.

## Ход работы

Собрана схема из следующих блоков:

| Блок | Назначение | Ключевые параметры |
|---|---|---|
| **PlutoSDR Source** | приём сигнала с устройства | LO = 101 МГц, Sample Rate = 2.4 МГц (переменная `samp_rate`), Manual Gain = 70 дБ, RF Bandwidth = 20 МГц |
| **QT GUI Frequency Sink** (после Pluto) | спектр широкой полосы для поиска станции | центр 101.2 МГц, полоса 2.4 МГц |
| **Low Pass Filter** | выделение полосы нужной станции | Cutoff = 100 кГц, Transition = 50 кГц, Decimation = 5, окно Hamming |
| **QT GUI Frequency Sink** / **Time Sink** (после ФНЧ) | контроль спектра и формы сигнала | полоса 480 кГц |
| **WBFM Receive** | демодуляция широковещательного FM | Quadrature Rate = 480 кГц, Audio Decimation = 10 |
| **Audio Sink** | воспроизведение звука | 48 кГц |
| **QT GUI Range** (`tune`) | ползунок частоты | 87–110.1 МГц, шаг 0.1 МГц |

Логика выбора параметров:

- FM-станция занимает полосу около 200 кГц, поэтому частота среза ФНЧ — 100 кГц (по половине полосы в каждую сторону от несущей).
- Частота дискретизации снижается по цепочке: 2.4 МГц → (÷5, ФНЧ) → 480 кГц → (÷10, WBFM) → 48 кГц, что подходит для воспроизведения звука.
- Частотные синки нужны, чтобы визуально найти станцию и проверить результат фильтрации.
